# Base privée Planète Chanvre

Ce dossier contient les documents de l'entreprise convertis en fiches Markdown
(fiches techniques produits, argumentaire, lexique…). **Son contenu n'est jamais
versionné** : seul ce README l'est (voir `.gitignore`), car le dépôt GitHub est public.

- Déposer les originaux dans `sources/`, puis lancer depuis `backend/` :
  `python -m scripts.importer_documents` (voir le README principal).
- `acces: interne` dans l'en-tête d'une fiche = visible uniquement par le profil
  « Équipe commerciale » ; `acces: public` = utilisable pour tous les profils.
- Pensez à sauvegarder ce dossier (Drive, NAS…) : il n'est pas sur GitHub.
