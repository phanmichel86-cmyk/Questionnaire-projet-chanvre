# 🐼 Panda Maman — Suivi de grossesse / Theo dõi thai kỳ

Application de suivi de grossesse, mignonne et bilingue **français / vietnamien**, au thème panda kawaii. Un seul fichier (`index.html`), aucune installation, fonctionne hors-ligne.

## Fonctionnalités

| Onglet | Fonctions |
|--------|-----------|
| **Suivi / Theo dõi** | Semaine de grossesse et trimestre calculés depuis la date de terme (ou les dernières règles), compte à rebours, barre de progression sur 40 semaines, taille du bébé semaine par semaine (comparaison fruit/légume + panda), journal hebdomadaire, checklist des étapes médicales importantes (calendrier français). |
| **Gourmand / Ăn uống** | Liste d'aliments classés **à volonté / avec prudence / à éviter**, avec la raison. Recherche et filtres. |
| **Recettes / Công thức** | Bibliothèque de recettes faciles filtrables par **type de cuisine** (vietnamienne, française, autre), **envie** (réconfort, frais, sucré, salé) et **ingrédient**. Recettes vietnamiennes incluses (cháo gà, canh chua, gà kho gừng…). Favoris. |
| **Exercices / Vận động** | Exercices adaptés à chaque trimestre (marche, yoga prénatal, natation, périnée…) avec conseils de sécurité. |

## Utilisation

Ouvre simplement `index.html` dans un navigateur (ordinateur ou mobile). Les données (date de terme, journal, étapes cochées, recettes favorites, langue, thème) sont enregistrées localement dans le navigateur.

- **Langue** : bouton FR / VI en haut à droite.
- **Thème** : bouton 🌙 (clair / sombre / système).
